# Göz - Android uygulaması (Aşama 2)

1. Android Studio > File > Open > bu klasörü (EyesKeychainApp) seç.
2. Gradle senkronizasyonu bitene kadar bekle (ilk sefer birkaç dakika, internet gerekir).
3. Telefonda: Ayarlar > Telefon hakkında > Yapım numarasına 7 kez dokun (Geliştirici seçenekleri açılır).
   Geliştirici seçenekleri > USB hata ayıklama: AÇIK.
4. Telefonu USB ile bilgisayara bağla, telefonda "USB hata ayıklamaya izin ver" de.
5. Android Studio'da üstte telefonunu seç, yeşil ▶ (Run) tuşuna bas.

Anahtarlık: Goz-XXXX adıyla bulunur. İlk bağlantıdan sonra adresi hatırlar, açılışta kendiliğinden bağlanır.
